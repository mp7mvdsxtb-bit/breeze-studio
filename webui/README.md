# Breeze Studio 2 · 英语配音工作台

双击上一级目录的 **启动语音工作室.bat**，或访问 <http://127.0.0.1:7861/?v=2>。
不必另外启动 API。首次启动需要加载模型，加载期间也能提交任务等待处理。

## 日常英语配音

### 用中文描述声音，翻译成英文

在「声音设计」或「声音指导」中：

1. 在「中文声音描述」填写音色、口音、情绪和表达方式（最多 600 字符）。
2. 点击 **翻译为英文**。英文预览可以修改。
3. 点击 **采用英文描述**，译文会填入下方实际用于配音的描述栏。中文草稿保留。

单条生成、配方和批量任务都使用已采用的描述，不会擅自把未采用的草稿提交给模型。中文修改后需要重新翻译。
翻译在本地 CPU 上运行，无需 API Key；较自由的描述首次翻译需要加载模型。专用配音术语和否定条件会优先处理，例如「气泡音」对应 vocal fry。
通用机器翻译仍可能有不准确之处，请检查英文预览后采用。

本地通用翻译模型为 [Helsinki-NLP/opus-mt-zh-en](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en)，由赫尔辛基大学开发，采用 CC-BY-4.0。模型和原始模型说明保存在 `breeze-runtime\translation-model`。

默认音色偏好为「清亮通透 · 干净实声」，每次声音设计和声音指导会自动附加清晰、平滑、减少沙哑/气声/气泡音的要求。也可选择「圆润饱满」。该偏好在后端应用，旧配方缺少此字段时同样默认清亮。

不喜欢某条结果时，可点「避开这个音色 · 不再复用」：保留历史文件，排除这条结果和它所使用的参考音频；匹配的参考音频不能再次用于生成或重复上传。此功能记录用户反馈，不会自动识别所有听起来相似的沙哑声音。
纯声音克隆会继承参考音色，不能靠清亮选项修复沙哑参考；应换参考音频，或使用声音指导。自然语言音色控制不能保证每次声音都符合听感偏好，建议先试听短句再批量生产。

1. 在「语音创作」中选声音设计、声音克隆或声音指导。
2. 输入英语文案。选择美式 UGC、自然女声、沉稳男声、英式讲述、产品演示等预设，或手写英文声音描述。
3. 点击「加入生成队列」。可以连续提交，不必等前一条结束。
4. 在预览区试听或下载 WAV；任务执行时可点「边生成边试听」。

英语预设只是描述起点，不保证口音、情绪完全符合预期。正式使用前请试听，尤其检查产品名、数字、专业词和结尾。
中文同样支持，生成中文时建议把声音描述也改成中文。

## 大量生成

- 「批量配音」支持一次 1–200 条文本，复用创作页的全部声音和参数。
- 导入 UTF-8 TXT：每个非空行是一条。
- 导入 UTF-8 CSV：须有 `text` 列，支持 CSV 标准引号内的逗号、换行。
- 粘贴多条文本：用独立一行 `---` 分隔；单条内部可以换行。
- 每条最多 30000 字符，每批总计最多 200000 字符；候选版本可选 1–4 个，每版使用相邻种子。
- 待执行队列上限 1000 项。8GB 显卡逐条执行，避免并行显存溢出。
- 「任务与历史」可搜索、分页、过滤状态、取消、重试、复用参数。
- 暂停队列仅停止领取新任务，当前任务继续完成。也可取消全部排队任务，再逐条重试。
- 本批 ZIP / 全部完成音频 ZIP 包含 WAV 和 `manifest.json`，可对照文件、原文和参数。

## 长文与稳定音色

长文优先按英文句子和空白分段，超过分段长度的超长句会进一步切分。默认每段 350 字符，支持 100–500；可先预览分段。每段独立生成后拼接，可设置 0–2000 毫秒段间静音。

纯文字设计声音不保证长文每段音色绝对一致。想长期使用某个声音，建议先生成满意的短音频，再点「将此音色存入声音库」，后续使用「声音克隆」或「声音指导」。

声音库保存参考音频与完整准确文字，支持 WAV/FLAC/MP3，0.5–60 秒、最多 30MB。文件会转成单声道 WAV 保存在 D 盘，不会在生成后删除。参考文字与实际音频不一致会影响效果；重复的原音频内容也应在文字中体现。

## 模型控制

- 三种模式：声音设计、声音克隆、声音指导。
- 英文发声事件：`(laugh)`、`(sigh)`、`(cough)`、`(clears throat)`；中文可直接输入 `[笑]`、`[叹气]`、`[咳嗽]`、`[清嗓子]`。
- CFG 描述引导、随机种子、Temperature、Top-p、Top-k、重复惩罚、音频帧数上限和随机采样/贪心解码。
- Temperature/Top-p/Top-k/随机采样作用于当前运行时的主干和深度解码阶段。参数在当前请求结束后恢复，不影响后续请求。
- 克隆模式不使用 instruction，CFG 固定为 1；要改变表达方式请切换声音指导。
- 750 音频帧约 60 秒，最高 1500。达到上限的输出会提示可能截断，需试听确认。
- 可选峰值统一至 −1 dBFS，这是音频后处理；流式试听为处理前的原始音量。
- 配方保存在当前浏览器，声音库、任务和音频保存在 D 盘。

模型没有精确语速/音高旋钮，也不提供逐词时间戳；语速与情绪通过自然语言描述控制。

## 硬件边界

当前机器为 Windows + RTX 5060 8GB，使用 CPU 文本模块与 GPU 语音模块的低显存适配。
官方推荐单请求至少 12GB，完整加速路径建议 24GB。本机不启用原生 GPU 并行批次、CUDA Graph 和编译加速。界面的批量功能是持久化串行队列，不冒充 GPU 并行推理。
这是运行策略限制；流式生成、三种声音模式及上述采样控制可用。不要同时运行旧的命令行模型或另一个模型服务。

## 恢复与停止

- 任务通过 SQLite 保存，刷新页面不丢任务。关浏览器不会停止任务。
- 排队任务在重启后继续排队；运行中被中断的任务显示「已中断」，点击重试会复用已完成分段。
- 取消当前任务后，GPU 需要短暂释放资源。队列自动等待并重试 HTTP 409，不会立刻让下一条任务失败；最多等待两分钟。
- 不自动重放已经开始但传输失败的音频，避免重复结果；需要手动重试，完整分段可复用。
- 需要停止时双击 **停止语音工作室.bat**，再用启动脚本重新打开。
- 模型启动失败时查看 `model-server.log`；界面异常查看 `webui-error.log`。

## 数据位置

`D:\kreado-pipeline\breeze-runtime\outputs\studio`

- `studio.sqlite3`：任务、声音元数据、队列设置。
- `voices`：参考音频。
- `<任务ID>.wav`：最终音频。
- `<任务ID>_parts`：已完成分段和未完成的临时分段，供续作。
- `history.json`：旧版历史，启动时迁移，原文件保留。

备份时建议先停止工作室，再复制整个 `outputs\studio` 文件夹。原版 UI/后端代码备份保留在 `webui\backup-v1`。

## 验证

自动测试覆盖参数校验、事务批量提交、断点续作、取消/重试、模型忙碌等待、队列持久化、参考声音、音频拼接、峰值处理、ZIP、文件导入和 API 请求清理。浏览器测试覆盖四页、手机布局、配方保存、CSV 提交和声音库选择。

真实模型另行验证英语批次、长文分段、原始 PCM 流式输出、声音克隆、声音指导，以及取消后继续处理下一项。测试脚本为 `test_studio.py`、`test_server.py`、`v2_browser.cjs`、`verify_real_v2.py`，模型参数测试位于 `app\tests\test_studio_controls.py`。

这些验证不等于所有输入都无错误，也不替代人工检查口音、发音、内容准确性和自然度。
